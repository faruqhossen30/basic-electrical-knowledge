# Rules

- সর্বদা সমস্ত প্রশ্নের উত্তর এবং ব্যাখ্যা বাংলা ভাষায় প্রদান করুন (Always explain and answer in Bangla language).
- কাজ শুরু করার পূর্বে সর্বদা একটি ইমপ্লিমেন্টেশন প্ল্যান (Implementation Plan) তৈরি করুন এবং ব্যবহারকারীর অনুমোদন/'Proceed' পাওয়ার পরেই মূল কাজ শুরু করুন (Always create an implementation plan and request user feedback with 'RequestFeedback: true'; only proceed with the implementation after the user clicks 'Proceed' or gives approval).
